# 공통 UI 구조

`package/home/src/common/ui`는 앱 안에서 재사용하는 UI를 다음 네 계층으로 구성합니다.

- `atoms` — 아이콘, 스피너처럼 독립적으로 재사용하는 최소 표현 단위입니다.
- `elements` — 버튼, 입력 필드, 테이블처럼 호출부가 하나의 UI 부품으로 사용하는 단위입니다. 필요하면 atom이나 MUI 부품을 조합합니다.
- `modules` — 반복 입력처럼 여러 UI 부품을 하나의 상호작용이나 표시 패턴으로 묶습니다.
- `template` — 편집 영역처럼 화면에 바로 배치할 수 있는 공통 섹션입니다. 필요한 동작은 props로 받습니다.

상위 계층은 필요한 하위 부품을 직접 사용할 수 있습니다. 분류는 내부 JSX의 개수보다 호출부에 제공하는 역할을 기준으로 합니다. 실제 재사용 단위가 생길 때 작은 부품을 분리합니다.

라우트 진입 제어와 로딩 fallback은 `routing`에서, Redux나 React Query에 연결된 전역 UI는 `ui-kit/app`에서 조립합니다. 업무별 폼과 데이터 연결은 `domain`에 둡니다. 이동한 컴포넌트의 기존 파일은 호환용 re-export이며, 새 코드는 구현 경로를 사용합니다. 단수형 `template`을 공통 섹션 경로로 사용합니다.
