# 프로필 요약 API v1

- 기존 자기소개서 및 경력 API와 호환된다. 프롬프트 생성과 AI 결과 가져오기는 브라우저에서 수행한다.
- `GET /api/v1/profile-summary`는 인증 사용자 자신의 저장본을 200으로 반환한다. 저장본이 없으면 204다.
- `PUT /api/v1/profile-summary`는 인증 사용자의 저장본 전체를 교체하고 204를 반환한다. 소유자는 인증 정보에서 가져온다. 같은 본문을 재시도해도 저장본이 늘어나지 않는다.
- `GET /api/v1/public-profile-summary/{userId}`는 공개 저장본을 200으로 반환한다. 비공개, 미저장, 미존재는 모두 204다. 응답은 저장하지 않도록 캐시를 지정한다.
- 저장 및 응답 본문은 `{"headline":"한 줄 소개","strengths":[{"title":"강점","evidence":"근거"}],"workingStyle":"일하는 방식","representativeExperience":"대표 경험","published":false}` 형태다. 필드는 필수다. 강점은 1~3개, 한 줄 소개는 200자, 강점 이름은 100자, 근거는 600자, 일하는 방식과 대표 경험은 각각 2000자까지 허용한다. 잘못된 입력은 400이다.
- 공개 여부는 요약 자체의 설정이다. 공개할 텍스트는 저장 전에 사용자가 검토한다. 원본 기록과 생성 프롬프트는 요약 테이블에 저장하지 않는다.
- PostgreSQL에는 `docs/migrations/profile-summary.sql`을 적용한다.
- 임시 PostgreSQL과 실제 HTTP 요청으로 소유자 격리, 입력 검증, 비공개 저장, 공개 전환 및 해제를 확인했다. Chrome에서 자기소개서와 네 카테고리 경력의 프롬프트 생성, JSON 초안 가져오기 및 공개 화면을 확인했다.
