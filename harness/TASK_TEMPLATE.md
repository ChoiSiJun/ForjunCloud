# 담당 에이전트 작업서

작업 규모에 맞춰 필요한 항목만 채운다. 전체 대화·전체 소스·장문의 로그를 복사하지 않는다.
기본 백엔드 작업은 메인이 수행한다. 이 작업서는 주로 독립 프런트 위임에 사용하며,
백엔드 보조를 사용할 때는 메인과 겹치지 않는 범위를 명시한다.

- 작업 ID / 담당: backend 또는 frontend
- 목표: 사용자가 관찰할 변경 한두 문장
- 소유 경로: 담당이 수정할 저장소와 파일 범위
- 관련 파일·심볼: 시작점과 참고 예제
- 적용 지침·스킬: 이번 작업에 필요한 경로만 지정
- 확인한 사실: 메인이 이미 조사한 내용과 기존 사용자 변경
- 유지할 사항: 구조·스타일·호환성·변경하지 않을 계약
- API 계약: 해당하는 경우 계약 문서 경로와 버전
- 완료 조건: 성공·실패·권한·경계 조건 중 관련 항목
- 검증: 필요한 명령, 환경, 브라우저 확인 범위
- 의존성: 다른 담당 결과를 기다려야 하는 부분

## 반환 형식

- 변경 파일과 사용자 동작 변화
- API 계약 영향: 없음 또는 구체 변경
- 검증: 명령 / 종료 코드 / 확인한 범위
- 미해결: 코드 실패 / 환경 실패 / 미실행 구분
- 메인에게 필요한 결정이나 후속 작업

계약 변경이 발견되면 다른 담당이 추측으로 진행하지 않도록 메인에 즉시 전달한다.
